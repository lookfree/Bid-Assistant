# 智启元投标助手 · 产品说明文档

**版本**：v1.0（对应产品版本 2026-07-29）
**适用读者**：使用者、售前、客服、实施人员

---

## 一、快速开始

### 1.1 注册登录

手机号 + 短信验证码登录，未注册的手机号自动创建账号。首次注册**一次性赠送 200 积分**，可完整体验全流程。

### 1.2 五分钟跑通一份标书

1. **新建标书** → 上传招标文件（可一次传多个：公告、主文件、技术规范书、补遗、附件）
2. **招标解读** → 点击生成，几分钟后得到评分点、要求清单、废标红线
3. **提纲生成** → 自动搭建技术标 + 商务标提纲，可自由增删调整
4. **标书生成** → 设定目标字数后生成正文，可在线编辑、AI 改写
5. **标书审查** → 废标风险体检，按建议整改
6. **导出文件** → 一键导出 Word / PDF

> 每一个消耗积分的步骤都需要你**主动点击确认**，系统不会自动扣费。

## 二、功能模块详解

### 2.1 新建标书 / 上传招标文件

- **支持格式**：`.pdf` `.docx` `.doc` `.xlsx` `.xls`
- **多文件**：一次最多 10 个文件，系统合并解读。建议把公告、主文件、技术规范书、补遗一起传，解读更完整
- **上传后**自动创建项目，进入解读环节

### 2.2 招标解读

**产出内容：**

| 板块 | 内容 |
|---|---|
| 项目信息 | 项目名称、采购编号、采购人、预算、投标截止时间 |
| 技术要求 | 逐条技术需求，标注★/▲ 实质性条款 |
| 商务要求 | 商务条款、付款、交付、售后要求 |
| 资格要求 | 投标人资格条件、证书、业绩要求 |
| 评分办法 | 评分项与分值，映射到章节 |
| 废标红线 | 可能导致投标无效的硬性条款汇总 |
| 投标文件构成 | 招标文件规定的章节与必备表单清单 |

**使用要点：**

- 左侧是招标原文、右侧是识别结论，**点击任一条目即定位到原文对应条款**，方便核对
- **多包件项目**：系统自动识别包件划分。一包一份投标文件，需先选定包件才能生成提纲。要投多个包，用"再投一个包"克隆项目
- 识别不全时：检查是否有未上传的附件（技术规范书常常单独成册）

**消耗**：20 积分 / 份

### 2.3 提纲生成

自动生成技术标 + 商务标提纲，每条子项标注来源条款。

**可做的编辑：**

| 操作 | 说明 |
|---|---|
| 增删章节 / 子项 / 小节 | 支持章 → 节 → 小节三级结构 |
| 改标题、改编号 | 章号支持自定义（如"附录A"） |
| 拖拽排序 | 拖住手柄可在**同层内**调整顺序，编号自动重排 |
| 章节上下移动 | 章标题行的 ↑↓ 按钮 |
| 组顺序切换 | "技术标在前 / 商务标在前"，部分招标文件要求商务标在前 |
| 编号模式 | "全文连续"（技术标接商务标顺排）/"分组各自"（各自从第一章） |

**改完必须点「保存提纲」**，否则不会带入后续生成。

**消耗**：30 积分 / 份

### 2.4 标书生成（正文）

点击"生成投标正文"后，先设定生成配置：

- **目标字数**：系统按预算规模与当前排版给出建议值（约一万元预算对应一页），可拖动调整，范围 1 万–50 万字
- **输出格式**：字体、字号、行距、页边距（也可以在导出时再调）

**生成过程**：AI 按提纲逐章撰写，界面实时显示"已完成 X/N 章"。章节多、招标文件大时约需 5–15 分钟。**可以离开页面**，回来自动接续显示进度。

**生成后可做的事：**

- **在线编辑**：富文本编辑器，支持标题层级、列表、表格、插图；失焦自动保存
- **AI 改写单章**：在右侧助手中选中章节、输入指令（如"把响应时间改为 15 分钟""本章更正式一些"），AI 改写后替换该章
- **撤销**：编辑器支持两级撤销（细粒度编辑 + 跨保存版本回退）
- **从资料库插入**：把企业资质、业绩案例等素材直接插入正文

**消耗**：按产出总字数分档计费

| 产出字数 | 消耗 |
|---|---|
| ≤ 5 万字 | 40 积分 |
| ≤ 15 万字 | 80 积分 |
| ≤ 30 万字 | 150 积分 |
| 更多 | 260 积分 |

**单章改写**：25 积分 / 次

### 2.5 标书审查

**废标风险审查**：全文合规体检，输出：

- **体检分**（0–100）
- **高风险 / 中风险清单**：每条含风险描述、所在章节、**整改建议**
- **通过项**：已符合要求的检查点

> 整改建议为**会员权益**，免费版可见风险清单，开通会员后可见完整整改建议。

**标书查重**：与既往标书做多维指纹比对，识别雷同段落。

- 三档策略：快速 / 标准 / 严格
- **自动剔除对招标文件的法定引用**（必须照抄的条款不算雷同）
- 输出相似度评分与高相似句对证据

**终审核对表**：系统根据本项目招标文件生成针对性核对表，逐项打勾自查。

**消耗**：废标审查 60 积分 / 次；查重 100 积分 / 次

### 2.6 述标演示

把投标文件提炼为述标 PPT：

- 按 **10 / 15 / 20 分钟** 时长组织内容
- 每页含要点 + **口播稿**
- 预生成**评委问答要点**
- 三款内置模板，或**套用企业自有 PPT 母版**（专业版权益）

**消耗**：80 积分 / 次

### 2.7 导出文件

导出符合投标惯例的完整 Word 文件，同时产出 PDF。

**文件结构**：封面 → 目录（Word 域，打开后按 F9 更新页码）→ 各章正文 → 资格证明附录 → 签章页

**排版**：默认宋体小四正文、黑体纯黑标题、1.5 倍行距、标准页边距；**导出弹层可自定义**字体/字号/行距/页边距，改完立即生效。

**重要说明**：

- **每次导出都按当前内容重新生成**。你的编辑、AI 改写、提纲调整都会体现在新文件里
- 因为要重新渲染，导出需等待几十秒（大标书更久），不是卡住
- **首次导出扣 20 积分，之后重新导出免费**，积分为 0 也能重新导出

### 2.8 我的资料库

沉淀企业素材，分类管理：企业资质、业绩案例、人员信息、技术方案、PPT 模板等。

**用途：**

- 写正文时作为**参考资料**被 AI 检索引用（内容更贴合企业实际）
- 编辑器中**直接插入**
- **资质证照**图片在导出时自动生成"资格证明文件"附录
- **PPT 母版**用于述标演示（专业版）

资料按账号隔离，仅本人可见可用。

## 四、常见问题

**Q：生成到一半关掉浏览器会怎样？**
任务在服务端继续运行。回到页面会自动接续显示进度，不会丢失、也不会重复扣费。

**Q：为什么导出要等这么久？**
每次导出都会按你当前的正文重新生成文件，确保你的编辑和 AI 改写都在里面。大标书渲染需要几十秒。

**Q：改了正文，导出的文件是新的吗？**
是。任何编辑、AI 改写、提纲调整都会在下次导出时体现。

**Q：识别出的要求不全怎么办？**
先检查是否有未上传的附件——技术规范书、评分办法常常单独成册。补传后重新解读即可。

**Q：生成的响应函和招标文件给的格式不一样？**
系统会尽量复刻招标文件自带的格式。若无法完全复刻，会在该处**主动加提示**让你对照原文核对。若招标文件中根本没检索到该表格式，也会明确提示"以下为通用格式，请对照招标原版核对"。

**Q：多包件项目怎么投多个包？**
一包一份投标文件。先选定一个包完成流程，再用"再投一个包"克隆项目投另一个包。

**Q：生成的字数和我设定的目标差多少？**
系统会按目标控制篇幅。导出后界面会显示文件的**真实页数**，可据此调整目标值。

**Q：AI 会编造资质和业绩吗？**
不会。缺材料处会显式标注"（待补充：…）"，需要你补充真实信息。

**Q：数据安全吗？**
项目与资料库按账号隔离；不使用你的招标文件或标书内容训练模型；导出文件末尾恒定附带 AI 生成说明（符合算法备案要求）。企业客户可选择私有化部署，数据完全不出域。

## 五、使用建议

**上传阶段**：把能拿到的招标文件全部一次传齐（公告 + 主文件 + 技术规范书 + 补遗 + 附件），解读完整度直接决定后续质量。

**提纲阶段**：这是投入产出比最高的环节。花十分钟把提纲调准（章节顺序、编号方式、必备表单是否齐全），正文质量会显著提升——因为正文严格按提纲生成。

**生成阶段**：目标字数不要贪多。评审看的是内容质量，注水反而扣分。系统建议值已按预算规模与评分权重算过，一般直接采用即可。

**审查阶段**：不要跳过。废标风险审查和终审核对表能挡掉大部分低级失误，成本远低于废标。

**导出阶段**：Word 打开后按 **F9 更新目录页码**。检查一遍"（待补充：…）"的位置，补齐真实信息后再递交。

## 六、名词表

| 名词 | 含义 |
|---|---|
| **★/▲ 条款** | 招标文件中的实质性要求，不满足即废标 |
| **废标红线** | 可能导致投标无效的硬性条款 |
| **偏离表** | 逐条列出投标响应与招标要求的偏离情况的表格 |
| **包件** | 招标项目的分包划分，一包对应一份独立投标文件 |
| **体检分** | 废标风险审查给出的 0–100 分合规评分 |
| **积分** | 平台内的使用计量单位，通过注册赠送、会员发放或充值获得 |
